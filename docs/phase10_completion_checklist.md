# Phase 10 completion checklist

Phase 10 is **complete** only when **all** items below pass. Do not start Phase 11 (frontend, dashboard, or React) until this checklist is satisfied.

## Required gates

| # | Gate | How to verify |
|---|------|----------------|
| 1 | `test_phase10_reports_metrics.py` passes | `cd backend` → `pytest app/tests/test_phase10_reports_metrics.py -v` |
| 2 | `test_phase10_scope_guard.py` passes | `pytest app/tests/test_phase10_scope_guard.py -v` |
| 3 | Full backend test suite passes | `pytest app/tests -v` |
| 4 | `phase10_clean_reset.ps1` succeeds | From project root: `.\scripts\phase10_clean_reset.ps1` |
| 5 | Backend started fresh after reset | `uvicorn app.main:app --reload --host 127.0.0.1 --port 8000` |
| 6 | `phase10_prepare_workflow.ps1` succeeds | `.\scripts\phase10_prepare_workflow.ps1` → `PHASE 10 WORKFLOW PREPARATION: PASS` |
| 7 | `capture_phase10_evidence.ps1` succeeds | `.\scripts\capture_phase10_evidence.ps1` → `PHASE 10 EVIDENCE CAPTURE: PASS` |
| 8 | Evidence pack has `test_results.txt` | `docs/evidence_pack/test_results.txt` |
| 9 | Evidence pack has safe API outputs | `docs/evidence_pack/api_outputs/*.json` (and safe HTML if generated) |
| 10 | Evidence pack has JSON report output | `docs/evidence_pack/api_outputs/report_json_generate.json` |
| 11 | Evidence pack has HTML report output | `docs/evidence_pack/api_outputs/report_html_generate_meta.json` (and optional `.html`) |
| 12 | Evidence pack has metrics output | `docs/evidence_pack/api_outputs/evaluation_metrics.json` |
| 13 | No raw sensitive values in evidence pack | Capture script raw scan = PASS |
| 14 | No overclaim phrases in evidence pack | Capture script overclaim scan = PASS |
| 15 | Phase 11 / frontend / dashboard not started | No new React, dashboard routes, or Phase 11 UI work |

## Pytest and shared development database

The capture script runs `pytest` first, then runs `alembic upgrade head` and `seed_phase2` again. Pytest fixtures drop and recreate tables on the same PostgreSQL URL used by uvicorn, so live API steps would fail without this repair step.

After `phase10_clean_reset.ps1`, start uvicorn in a **fresh** terminal. If port 8000 is already in use by an old process, stop it before starting the API.

## False completion guard

**Do not mark Phase 10 complete** if:

- `capture_phase10_evidence.ps1` exits non-zero or prints `PHASE 10 EVIDENCE CAPTURE: FAIL`
- `capture_summary.json` has `"pass": false`
- `capture_status.md` shows **Final: FAIL**
- API capture was skipped because the backend was down (pytest alone is not enough)
- Live API database is out of sync with migrations/seed (health shows database not connected)

## Recommended order

```powershell
.\scripts\phase10_clean_reset.ps1
# separate terminal:
cd backend
.\.venv\Scripts\Activate.ps1
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
# project root:
.\scripts\phase10_prepare_workflow.ps1
.\scripts\capture_phase10_evidence.ps1
```
